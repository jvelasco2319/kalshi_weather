# Initial colonies

These are default research responsibilities. Replace their briefs before registration when another division is more useful.

| Colony | Main responsibility | Typical follow-up |
|---|---|---|
| `formulations` | Clarify the main question, baselines, easier variants and competing formulations | Test whether a simpler related question isolates the obstacle. |
| `mechanisms` | Propose causal or mathematical explanations and executable methods | Fork a useful parent, combine two distinct parents, or test a contrary mechanism. |
| `measurement` | Verify data meaning, calculations, sample coverage and consistency | Reproduce results; identify whether the measured gain supports the stated claim. |
| `falsification` | Attack the strongest candidate with controls, alternative explanations and failure cases | Find leakage, proxy assumptions, fragile groups or counterexamples. |

Each proposal states its strongest counter-hypothesis. Each candidate needs two named reviewers from different nonproposing families. A child belongs to the same independent family as its parent; parent and child cannot independently review one another.

At hourly reflection, a child can specialize a reproduced all-gate parent's useful question. Its proposals still use the frozen experiment language. A novel language or new inputs require a successor campaign. Child colonies do not receive extra hosted slots merely because a new name exists.

The default cap is eight total colonies, including retired ones, within four hosted task slots including the coordinator. The host rotates work, leaves idle slots idle when no useful task exists, and preserves adversarial review capacity.
