# Research release checklist

Complete this against the actual investigation before treating its claims as accepted. A checked box cannot substitute for the underlying evidence.

- The final statement addresses the original contract version, definitions, assumptions, exclusions and accepted scope.
- Actual models, tool permissions, concurrency, provider controls and protected verification boundary match the runtime declarations.
- Every consequential claim cites original sources or artifacts at exact versions and locators.
- Execution, task delivery, research outcome, review, verification, acceptance and applicability are reported separately.
- Review objections, negative results, shared source origins and failed approaches remain available.
- Required domain checks actually ran on the intended statement, implementation, dataset and settings; scope and versions match the decision.
- Attempted, completed, excluded and reported runs reconcile, with reasons for exclusions and no hidden scaffold workload substituted for final evaluation.
- Dependencies are applicable; disputes and checker changes received recorded triage and revalidation.
- Ownership, fencing, retries, stale submissions, durable acknowledgment and outstanding provider attempts reconcile.
- Actual or unknown usage is retained; research did not consume protected verification/reporting allocations or refund cancellation costs.
- Delivery classification is separate from each hypothesis outcome; a budget stop is not objective satisfaction.
- The report's numbers, figures, citations and conclusions match stored evidence and name unavailable checks and unresolved gaps.
- Architecture comparisons disclose controlled models/versions, equal declared caps, actual/unknown costs, repeated runs and limits of generalization.
- A successor preserves the prior record and versions changed targets, methods, data or acceptance controls.

For partial or inconclusive work, identify the strongest checked result, missing step, retired approaches and the next discriminating action. Preserve enough state to continue without repeating the investigation.
