    Get Event Fee Changes

    Event fees are an override layered on top of the parent series’ fee structure. If fee_type_override and fee_multiplier_override are null, that indicates the override is cleared.

    Query Parameters

    ​
    event_ticker
    string
    ​
    limit
    integer<int64>
    default:100

    Number of results per page. Defaults to 100.

    Required range: 1 <= x <= 1000
    ​
    cursor
    string

    Pagination cursor. Use the cursor value returned from the previous response to get the next page of results. Leave empty for the first page.

    Response

    Event fee changes retrieved successfully

    ​
    event_fee_changes
    object[]
    required

    Show child attributes

    ​
    cursor
    string
    required

    Pagination cursor for the next page. Empty if there are no more results.
