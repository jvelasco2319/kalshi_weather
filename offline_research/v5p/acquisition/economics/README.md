# V5P public economics evidence

This directory is an additive V5P acquisition area. It does not amend the
frozen V5 registration, data, source bindings, or conclusions.

The acquisition is limited to free public fee schedules, official API/series
metadata, archived-official indexes, and CFTC/Kalshi contract-rule filings. It
does not request market outcomes, nested markets, protected confirmation
labels, orders, fills, private account data, or live feeds.
