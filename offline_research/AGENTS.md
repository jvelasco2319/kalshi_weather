# Project rules

- Read GOALS.md and README.md before implementation. GOALS.md is the current implementation contract and supersedes earlier online or prospective collection plans.
- Scope this project to Kalshi KLAX daily-high-temperature research. Defer generic multi-domain framework work. Verify specific contract rules and station before treating a market as eligible.
- Use finite historical downloads followed by frozen offline experiments. The prospective V7 schedule was paused before its first target date and superseded for the current task by completed historical replay V7H, covering August 4-September 14, 2026. Do not enable live feeds, continuous online recorders, or live/paper orders. Hosted agent reasoning may use Codex connectivity; replay and scoring must run without network access.
- Complete Goal 1 readiness checks before launching Goal 2. Never describe proposed commands as implemented, simulated results as actual profits, or estimated edge as realized return.
- Preserve raw source data and record source, retrieval time, issue time, and information-availability time.
- Never fabricate observations, historical forecasts, results, or completed implementation.
- Use chronological development and validation splits. Discovery agents must not access the protected final holdout.
- Fix scoring, market settlement mapping, costs, and evaluation criteria before testing candidates. Report calibration, forecast quality, uncertainty, and economic results separately.
- Enforce budgets, concurrency, permissions, state transitions, retries, and stopping rules in deterministic code. Agents propose; code validates and executes.
- Record hypothesis, task, experiment, and evidence IDs with code/data versions and artifacts.
- Replication and adversarial review must be independent of discovery. Agent agreement is not verification.
- Keep credentials, raw data, runtime databases, and large generated artifacts out of Git.
- Do not interpret the 10% target as a reason to continue searching until a favorable backtest appears. No improvement is a valid outcome.
- The confirmed objective is at least 10% expected net return per trade on total entry outlay, initially for purchased contracts held to settlement. Follow the formula in GOALS.md. Treat this as a research screen, not evidence of profitability or authorization to trade.
